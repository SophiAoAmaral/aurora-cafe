☕ Café Aurora
------------------------------------------

Uma landing page responsiva para uma cafeteria fictícia, desenvolvida com foco em uma experiência moderna, navegação fluida e interface elegante.

O projeto foi criado com o objetivo de praticar conceitos fundamentais do ecossistema React, como componentização, gerenciamento de estado com Hooks, roteamento e construção de interfaces responsivas utilizando Tailwind CSS.

🚀 Tecnologias
------------------------------------------
React,
Vite,
JavaScript,
Tailwind CSS,
React Router,


📚 Conceitos praticados
------------------------------------------
Componentização
SPA (Single Page Application)
React Router
Hooks (useState e useEffect)
Renderização dinâmica utilizando objetos e arrays
Gerenciamento de estado
Navegação entre páginas
Responsividade (Mobile First)
Organização de componentes e páginas


✨ Funcionalidades
------------------------------------------
Landing page moderna
Header responsivo
Menu mobile
Navbar com efeito durante o scroll
Carrossel animado
Seção "Nossa História"
Cardápio com filtros dinâmicos
Galeria do ambiente
Página de reserva de mesas
Seleção de quantidade de pessoas
Seleção de data
Seleção de horário
Formulário de reserva
Modal de confirmação da reserva
Layout responsivo para dispositivos móveis e desktop



🎯 Objetivo
------------------------------------------

Este projeto foi desenvolvido com fins de estudo para consolidar conhecimentos em React e Tailwind CSS, colocando em prática conceitos como componentização, gerenciamento de estado, criação de interfaces responsivas e desenvolvimento de aplicações SPA.
